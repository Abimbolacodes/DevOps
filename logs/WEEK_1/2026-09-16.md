## Day 3 — 16 Sep

### What I did
- Learned what branches are and why they're used
- Created a new branch (feature-script) off main
- Made a change and committed it on the branch (not on main)

### Commands I used
- `git branch` — list branches
- `git checkout -b feature-script` — create and switch to new branch
- `git add .` / `git commit -m "..."` — staged and committed on the branch

### What I learned
- A branch is like a separate copy of the code to experiment safely
- Changes on a branch don't affect main until merged
- Teams use branches so multiple people can work without overwriting each other
