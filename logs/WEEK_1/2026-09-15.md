 What I did
- Made changes to files in my repo
- Practiced the git workflow: status → add → commit → push
- Made my first real commit and pushed it to GitHub
- Checked commit history with git log

### Commands I used
- `git status` — to see what files had changed
- `git add .` — to stage all my changes
- `git commit -m "..."` — to save a snapshot with a message
- `git push` — to send my commit up to GitHub
- `git log --oneline` — to view my commit history

### What I learned
- The difference between the local repo (on my machine) and the remote repo (on GitHub)
- Staging vs committing — staging is choosing what to save, committing is actually saving it
- Why commit messages matter — they explain *why* a change was made, not just what
- A commit only exists locally until you push it
